# Bundled reference data

`srdCreatures.json` — the 322 creatures of the **System Reference Document 5.1**,
published by Wizards of the Coast under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), collected via the
[Open5e](https://open5e.com) API.

These are the only creatures Oracle treats as coming from an official source.
Anything written here or by the AI is homebrew and carries no official source.

The file is loaded into `oracle_creatures` by `scripts/seed-srd-creatures.mjs`.
